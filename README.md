# Hermes 安卓版

原生卡通外壳 + 内嵌 Hermes 自带网页界面。局域网直连飞牛 NAS，外网走 IPv6，
不经过微信或第三方服务器，聊天响应速度与 NAS 上自带 UI 一致。

App 不内置任何固定网址：启动时自动扫描局域网里的飞牛网关，外网线路由用户自己添加。

[下载 APK](https://github.com/wenming758/hermes-android/releases/latest) ｜
[源码仓库](https://github.com/wenming758/hermes-android)

## 功能

- **局域网自动发现**：启动时并发扫描当前 /24 网段的 5666 端口，识别 `飞牛 fnOS`
  网关后自动加入线路并探测；“设置 → 线路 → 扫描”可手动重扫。
- **线路自己管理**：无任何硬编码地址，可添加、编辑、删除任意 `http(s)://` 地址，
  支持域名、IPv4 和 IPv6 字面量（如 `http://[240e:…]:5666/`）。
- **线路策略**：首页可指定“自动选最快”或某一条线路；选好后点“进入 Hermes”即按该线路进入。
- **在线升级**：首页和设置页都有“检测更新”按钮，直接读取 GitHub Releases，
  显示更新说明与更新源，下载后调起系统安装。
- **快速直连**：并行探测所有线路，按页面内容判断可用状态并记录毫秒延迟，自动选最快线路。
- **DNS 兜底**：系统 DNS 拿不到 AAAA 时，自动用 UDP DNS / DoH 解析 IPv6，
  再用 IPv6 字面量直连，绕开手机 DNS 限制。
- **网关入口发现**：对飞牛 5666 网关尝试常见 Hermes 路径；
  没有登录时引导登录飞牛，并自动捕获 Hermes 入口地址。
- **登录保持**：共用系统 WebView 的 Cookie，登录一次后探测会带上 Cookie；
  设置里可随时清除登录状态。
- **沉浸式聊天**：进入聊天后自动隐藏底部系统导航栏，边缘滑动可临时唤出；
  设置里可关闭。网络在 Wi-Fi / 流量之间切换时，自动重连，必要时切换到可达线路。
- **掉线自愈**：页面出现红色“失联/连接中断”时自动检测并重载恢复；
  从后台回到前台会立即检查连接状态，无需手动刷新。
- **通知权限**：Android 13+ 首次启动会请求通知权限，也可在“设置 → 通知权限”里管理。
- **完整网页能力**：下载、文件上传、麦克风/摄像头授权、JS 弹窗、`window.open` 小窗、
  SSL 证书错误阻断、断网恢复后自动重试。
- **卡通界面**：机器人首页、贴纸按钮、彩色状态胶囊、星光动画。

## 安装

1. 下载 `Hermes-1.0.3.apk`（见 Releases）传到手机，点开安装（需允许“安装未知来源应用”）。
2. 首次启动无需配置：App 会扫描当前网段（约 3~5 秒），找到飞牛网关后自动添加并探测。
3. 若显示“需要登录飞牛”：点“登录飞牛并连接”，在飞牛桌面点开 Hermes 图标，
   App 会自动捕获入口地址并保存，之后可直接进入。
4. 要在外网使用：点“设置 → 线路 → 添加”，填入你的外网地址
   （例如 `http://your-nas.example.com:5666/` 或 `http://[240e:xxxx::1]:5666/`）。
   手机卡/宽带需开通 IPv6，路由器需放行 IPv6 入站 5666 端口。

扫描只覆盖手机当前所在的 /24 网段；NAS 在别的网段、或路由器隔离了无线客户端时，
请手动添加局域网地址（如 `http://192.168.1.22:5666/`）。

线路可在“设置 → 线路”里增删改，点“扫描”重新发现局域网网关，
“清空全部线路”会删除所有线路（不会恢复任何内置地址）。

## 外网排查

1. 看线路行右侧的原因：`当前网络无 IPv6 / 域名解析失败 / 连接超时 / 端口未开放`。
   - `当前网络无 IPv6`：当前网络确实没有公网 IPv6，换 5G 或开启路由器 IPv6。
   - `域名解析失败`：App 会自动改用 DoH/UDP 解析 IPv6；若仍失败，说明该网络连
     公共 DNS 也被拦截，可手动把线路改成 IPv6 字面量地址。
   - `连接超时 / 端口未开放`：解析正常，是运营商或路由器 IPv6 防火墙没放行 5666。
2. 关掉 Wi-Fi 用 5G 再试；手机浏览器打开 `test-ipv6.com`，不是 10/10 就说明当前网络没有 IPv6。
3. 手机上的 Clash/VPN/代理类 App 常会接管 DNS 并关闭 IPv6，先彻底退出再测试。
4. APN 里把“协议/漫游协议”设为 `IPv4/IPv6`，路由器的 IPv6 防火墙放行 NAS 的 5666 入站。

## 工作原理

1. **局域网发现**：枚举本机非回环 IPv4 地址，取所在 /24 网段，用 48 线程并发探测
   5666 端口，再按页面标题 `飞牛 fnOS` 确认是网关；找到的第一台自动写入线路，
   重复扫描不会产生重复线路。
2. **并行探测**：对每条线路发 HTTP GET，按页面内容判断 `可用 / 需登录飞牛 / 不可达`，
   记录毫秒延迟并自动选最快线路。
3. **DNS 兜底**：系统 DNS → UDP DNS（223.5.5.5 / 119.29.29.29 / 8.8.8.8）→
   DoH（阿里 DNS / Cloudflare）解析 IPv6，再用 IPv6 字面量直接访问。
   解析结果缓存 10 分钟，并随线路保存。
4. **网关发现**：对 5666 网关依次尝试 `/app/hermes/` 等常见入口；
   页面含 `invalid token` 视为“需登录”。
5. **登录捕获**：在 WebView 里打开飞牛桌面，注入脚本监听页面地址和 iframe，
   发现 `/app/…hermes…` 入口后弹窗确认，保存为线路。
6. **内嵌 UI**：进入后直接加载 Hermes 自己的网页，与 NAS 上原生 UI 同一套前后端，
   没有额外的消息中转延迟。
7. **网络切换重连**：监听默认网络变化，Wi-Fi / 流量切换后自动探测并重连；
   原线路不可达时，自动改用当前网络下可达的线路（例如切到局域网网关）。

## 自行构建

环境：JDK 17、Android SDK Platform 34、Build-Tools 34.0.0、Gradle 8.7。

```bash
cd HermesApp
./gradlew assembleRelease
```

`local.properties` 里的 `sdk.dir` 指向本机 SDK（该文件不入库）。
工程路径含中文时，`gradle.properties` 已启用 `android.overridePathCheck=true`。

### 签名

仓库不包含签名文件和密码。自行生成：

```bash
keytool -genkeypair -v -keystore HermesApp/hermes-release.jks \
  -alias hermes -keyalg RSA -keysize 2048 -validity 10000
```

然后在 `HermesApp/keystore.properties` 中填写（该文件已被 `.gitignore` 排除）：

```properties
storeFile=hermes-release.jks
storePassword=你的密码
keyAlias=hermes
keyPassword=你的密码
```

请自行备份 `.jks` 和密码；丢失后将无法覆盖升级已安装的版本。

## 安全与边界

- 没有硬编码 NAS 管理员密码或 API Key；登录只在 WebView 中由用户本人完成。
- 全部对话数据直连 NAS，App 不含统计、广告或第三方 SDK。
- 仅允许明文 HTTP（`network_security_config.xml`），因为飞牛网关通常使用 5666 端口；
  HTTPS 证书错误一律阻断，不会静默放行。
- 不修改 NAS 上的系统文件、反向代理配置或已有网站，也不新增/开放端口。

## 已知限制

- 局域网扫描只覆盖当前 /24 网段，跨网段或开启 AP 隔离时需手动添加地址。
- 外网速度取决于运营商 IPv6 上行质量；IPv6 不可用的网络只能走局域网。
- 登录令牌会随捕获的地址保存在本机；令牌过期时按提示重新登录即可。
- 若 NAS 上 Hermes 的网关路径不含 `hermes` 字样，自动捕获可能找不到，
  可在“设置 → 线路”里手动填入完整地址。
- 项目未在大量机型上验证；欢迎提交 Issue 反馈机型和系统版本。
